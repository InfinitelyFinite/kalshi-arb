# kalshi-arb

**kalshi-arb** is an automated cross-platform arbitrage and market-making engine designed to detect, analyze, and execute mispriced prediction market opportunities between Kalshi and Polymarket. The system supports multi-mode execution (dry-run, sandbox, and live trading), real-time order book synchronization, algorithmic contract matching, risk management controls, DuckDB analytics persistence, and a real-time web dashboard.
